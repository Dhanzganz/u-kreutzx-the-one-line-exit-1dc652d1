# The One-Line Exit

A single-line resignation letter: HR's "we're a family" speech finally convinces the employee to disown the whole company — the punchline flips the corporate family cliché into a breakup.

## Run

```sh
python3 main.py
```

Writes the entry text to `/output/entry.txt` (85 characters, one line, UTF-8).
